# Sales Data Analysis Dashboard | Power BI

This project is an interactive **Sales Dashboard** built using **Power BI** to analyze sales performance and key business metrics. The dashboard provides actionable insights for business decision-making and demonstrates data analysis, modeling, and visualization skills.

## 📊 Project Overview

The goal of this project is to transform raw sales data into meaningful insights through a clean and interactive dashboard. Key aspects include:

- **Sales trends** over time
- **Performance analysis** by product and category
- **Key Performance Indicators (KPIs)** for business decision-making
- **Interactive visuals** for user-friendly navigation

## 🗂 Dataset

The dataset used in this project is provided in **Excel format** and includes:

- Sales transactions
- Product categories
- Dates and regions
- Revenue and quantity sold

> Note: Data has been cleaned and preprocessed to ensure accurate reporting.

## 🛠 Tools & Technologies

- **Power BI** – for data modeling, visualization, and dashboard creation  
- **Excel** – for initial data source and preprocessing

## 🔧 Features

- Cleaned and transformed raw sales data  
- Created table relationships for accurate data modeling  
- Built interactive dashboards to explore:
  - Total sales by product and category
  - Sales trends over time
  - Regional performance analysis
- Visual KPIs for quick insights

## 🏆 Key Learnings

- Data cleaning and preprocessing techniques  
- Power BI data modeling and table relationships  
- Interactive dashboard design and visualization  
- Translating business questions into data insights
